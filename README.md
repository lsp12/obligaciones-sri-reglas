# Reglas tributarias — Obligaciones SRI

Archivo público que consume la app "Obligaciones SRI" para calcular fechas de vencimiento sin necesitar una nueva versión publicada.

- **Archivo:** `reglas.json`
- **URL pública (con GitHub Pages activado):** `https://lsp12.github.io/obligaciones-sri-reglas/reglas.json`

## Cómo actualizar una fecha o un feriado

1. Edita `reglas.json`.
2. Sube el número de `"version"` en 1 (la app solo aplica versiones mayores).
3. Haz commit y push a `main`. GitHub Pages publica el cambio en uno o dos minutos.

No borres ni renombres el archivo: la app ya apunta a esa URL exacta.
